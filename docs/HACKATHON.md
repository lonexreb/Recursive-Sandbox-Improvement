# Hackathon submission map

## One-line pitch

We let an AI scientist change the GPU-price forecasting method, but never the test: every
experiment runs in a fresh Modal sandbox that cannot see future truth, credentials, or its
own promotion gate.

## Submission choice

- Primary: **Track 2 — Recursive Self-Improvement by Pacific**.
- Sponsor challenge: **Modal — best use of Modal**.
- Tracks 1 and 3 are architectural inspiration, not additional primary-track claims.
- Originator is a trace export target if session upload is available; Exa and past.dev are
  documented seams, not claimed integrations.

## Two-minute demo

1. **0:00–0:15 — result first.** Show +0.219688 champion skill versus +0.183267 official
   drift on the same 4,209 cells and 12/15 origin wins. Show that the 90% interval crosses
   zero instead of hiding uncertainty.
2. **0:15–0:35 — the problem.** Ordinary self-improvement can rewrite its test. Point to
   the trusted boundary: truth, evaluator, resources, and promotion gate stay outside.
3. **0:35–1:05 — live loop.** Start `rsi-sandbox improve`; show proposals branching from
   the champion, fresh Modal sandboxes, rejected variants, and the promoted lineage.
4. **1:05–1:30 — inspect one trace.** Truncated history goes in; forecasts come out; show
   blocked network, no secrets/volumes, gVisor, limits, and request/response hashes.
5. **1:30–1:48 — recursive evidence.** Show equal-budget recursive versus fixed-anchor
   control and the planted/null calibration. State exactly what it proves and does not.
6. **1:48–2:00 — decision.** “At a $33.6k reference capex, our base 3-year H100 NPV is
   $25.1k: rent, do not buy, unless delivered cost is under $25k or utilization is >80%.”

## Track fit

- Track 2: the objective is calibrated quantile GPU-price skill over 1/3/7-day horizons;
  the official drift baseline is reproduced as a locked comparator.
- Recursive improvement: the mutation center moves only when a candidate passes a frozen
  promotion gate; an equal-budget fixed-anchor arm isolates inheritance.
- Modal: isolation is part of scientific validity, not merely compute hosting. Every
  candidate-origin evaluation receives only its causal history and produces a hashed result.

## Sponsor integration seams

- **Exa:** write a dated evidence bundle before the run; hash it into the manifest; never
  let live search enter a scoring sandbox.
- **past.dev:** publish typed proposal, critique, and result events to the shared timeline.
- **Originator:** attach the run/config/data hashes and champion parent to every trace.

These seams are outside the scoring boundary so a missing sponsor service cannot make the
benchmark irreproducible. They must not be presented as completed sponsor integrations.

## Judging claim

The strongest claim is not “we solved recursive self-improvement.” It is: “we built a
repeatable protocol where improvement can happen without candidates controlling their
own test, resources, credentials, or promotion.”

## Three-minute finals script

“Self-improving systems have a measurement problem: if the candidate can see future truth,
rewrite the scorer, or buy itself more compute, an apparent improvement is not science.

RSI makes that boundary executable. A trusted orchestrator gives each candidate only
history available at its forecast origin. Modal starts a fresh gVisor sandbox with outbound
network blocked, no secrets or volumes, and fixed CPU, memory, output, and time limits. The
sandbox returns q10, q50, and q90 forecasts. Only the trusted evaluator sees truth and decides
promotion.

On the official 97-series rolling scope, our frozen champion scores +0.219688 skill against
last value. The official drift baseline scores +0.183267 on the exact same 4,209 cells. That
is 4.46% less pinball loss and 12 wins across 15 weekly origins. The origin-block bootstrap
interval includes zero, so this is promising development evidence, not a conclusive or
hidden-test claim.

The recursion is testable too. Recursive and fixed-anchor control arms use the same mutation
operator, seeds, and charged candidate-origin attempts. The only difference is whether a
promotion becomes the next generation's parent. Synthetic planted effects compound; null
studies do not create false wins. Real prospective confirmation remains future work.

Finally, forecasting serves a decision. Using the pack's $33.6k H100 reference capex, our
base 3-year discounted cash flow is $25.1k. So our answer is rent—not buy—at reference price;
buy only below roughly $25k delivered or with a defensible path above 80% utilization.

The contribution is a falsifiable improvement protocol: the model may change the method,
but it can never change the test.”
